## Key Citations for Follow-up

- Bernstein (2003) - primary conceptual source for model-management operators.
- Rahm and Bernstein (2001) - automatic schema matching background for Rondo's Match operator.
- Melnik, Garcia-Molina, and Rahm (2002) - Similarity Flooding algorithm used by Match.
- Pottinger and Bernstein (2002/2003) - merge and mediated schema work behind Rondo's merge scenario.
